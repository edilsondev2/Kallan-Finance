# Kallan Finance — Roadmap

- [ ] Fase 1 — Fundação: design system, auth (e-mail+senha com confirmação, Google), banco + RLS, navegação
- [ ] Fase 2 — Início, movimentações, carteira (contas/cartões/investimentos manuais), categorias, metas, perfil
- [ ] Fase 3 — Kallan Intelligence: chat com IA, diagnósticos determinísticos, agentes, planos de ação
- [ ] Fase 4 — Open Finance: OpenFinanceProvider + adaptador Malvo (pendente de credenciais/documentação), consentimentos
- [ ] Fase 5 — Negócios: perfil empresarial, receitas/despesas, indicadores, metas
- [ ] Fase 6 — Comunidade: feed, perfis, curtidas, comentários, seguir, denúncia, bloqueio, vitrine, eventos
- [ ] Fase 7 — Validação: testes de regras, isolamento de dados, responsividade
